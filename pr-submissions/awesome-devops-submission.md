## Infrastructure as Code / Terraform Modules

### AWS

- [terraform-aws-vpc-complete](https://github.com/kogunlowo123/terraform-aws-vpc-complete) - Production-ready VPC with multi-tier subnets, NAT Gateways, flow logs, and VPC endpoints.
- [terraform-aws-eks](https://github.com/kogunlowo123/terraform-aws-eks) - Amazon EKS with managed node groups, Fargate profiles, IRSA, add-ons, and EKS Access API.
- [terraform-aws-ecs-fargate](https://github.com/kogunlowo123/terraform-aws-ecs-fargate) - ECS Fargate with service discovery, autoscaling, circuit breaker, and blue/green deployments.
- [terraform-aws-lambda](https://github.com/kogunlowo123/terraform-aws-lambda) - Lambda with layers, SnapStart, function URLs, event sources, and canary deployments.
- [terraform-aws-security-baseline](https://github.com/kogunlowo123/terraform-aws-security-baseline) - AWS security baseline with GuardDuty, Security Hub, Config, CloudTrail, Macie, and Detective.

### Azure

- [terraform-azure-aks](https://github.com/kogunlowo123/terraform-azure-aks) - Enterprise AKS with Azure CNI Overlay, Workload Identity, Defender, and Azure Policy integration.
- [terraform-azure-hub-spoke-network](https://github.com/kogunlowo123/terraform-azure-hub-spoke-network) - Hub-spoke network with Azure Firewall, Bastion, VPN Gateway, ExpressRoute, and Route Server.
- [terraform-azure-openai-platform](https://github.com/kogunlowo123/terraform-azure-openai-platform) - Azure OpenAI Service with model deployments, content filtering, and optional APIM front-end.
- [terraform-azure-container-apps](https://github.com/kogunlowo123/terraform-azure-container-apps) - Container Apps with Dapr, custom domains, scaling rules, managed certs, and VNet injection.
- [terraform-azure-security-center](https://github.com/kogunlowo123/terraform-azure-security-center) - Defender for Cloud with per-resource pricing, compliance automations, and security workflows.

### GCP

- [terraform-gcp-gke](https://github.com/kogunlowo123/terraform-gcp-gke) - GKE Autopilot and Standard clusters with Workload Identity and node auto-provisioning.
- [terraform-gcp-cloud-run](https://github.com/kogunlowo123/terraform-gcp-cloud-run) - Cloud Run services and jobs with custom domains, VPC connectors, and secret management.
- [terraform-gcp-bigquery](https://github.com/kogunlowo123/terraform-gcp-bigquery) - BigQuery datasets, tables, views, routines, row-level security, and data transfers.
- [terraform-gcp-cloud-armor](https://github.com/kogunlowo123/terraform-gcp-cloud-armor) - Cloud Armor with IP rules, geo-blocking, rate limiting, WAF, bot management, and adaptive protection.
- [terraform-gcp-composer](https://github.com/kogunlowo123/terraform-gcp-composer) - Cloud Composer (managed Airflow) with Composer 2/3, private networking, and custom workloads.

### Multi-Cloud

- [multi-cloud-landing-zone](https://github.com/kogunlowo123/multi-cloud-landing-zone) - Multi-cloud landing zone spanning AWS, Azure, and GCP with unified identity federation.
